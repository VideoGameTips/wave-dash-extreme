# Geometry Dash Trainer

An endless Geometry-Dash-style practice game split out from the PvP arena project.

Pick Wave, Cube, Ship, UFO, or Ball mode from the start menu. Spike Only becomes a grief-style tight-path pipe the longer you survive, while the other level pipes keep spawning harder spikes, lasers, traps, blackout sections, and right-side boss fights. Press `/` three times within one second to force Extreme Demon.

Open `index.html` in a browser to play.
