# Geometry Dash Trainer

An endless Geometry-Dash-style practice game split out from the PvP arena project.

Pick Wave, Cube, Ship, UFO, Ball, or Spider from the start menu. Each mode generates its own movement-specific course. Spider taps instantly switch between floor and ceiling; Ship has fast thrust reversal; Wave builds tighter slaloms over time. Spike Only becomes a grief-style tight-path pipe the longer you survive. Boss challenges remain available separately. Press `/` three times within one second to force Extreme Demon.

Open `index.html` in a browser to play.

Run `node verify-modes.cjs` for movement and obstacle regression checks.
