# Wave Dash Extreme

An endless Geometry-Dash-style wave survival game split out from the PvP arena project.

Hold mouse, touch, or Space to climb. Release to dive. The run keeps spawning harder spikes, lasers, traps, blackout sections, and right-side boss fights. Press `/` three times within one second to force Extreme Demon.

Open `index.html` in a browser to play.
